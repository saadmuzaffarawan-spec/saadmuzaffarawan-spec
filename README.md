## 🔥 Featured Project

### 🧩 PacketXTracer — C++ Network Packet Analyzer

PacketXTracer is a C++ OOP-based network packet analyzer and packet sniffer built using:

* C++
* Raylib
* PcapPlusPlus
* Npcap
* libpcap / wpcap
* G++ / MinGW

The project captures live network packets, detects protocols, displays packet details, and helps beginners understand how real network traffic works.

📌 Repository:
[PacketXTracer-Cpp-Network-Packet-Analyzer](https://github.com/saadmuzaffarawan-spec/PacketXTracer-Cpp-Network-Packet-Analyzer)

Main features:

* Live packet capture
* Network adapter selection
* TCP, UDP, ICMP, ARP, and unknown packet detection
* Source and destination IP extraction
* Port extraction
* Packet size display
* Packet log saving
* Raylib-based graphical interface
* Modular C++ OOP structure
